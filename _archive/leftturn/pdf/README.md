Drop the typeset issue PDFs here, named to match the `pdf:` field in
`src/content/issues/*.md` — e.g. `left-turn-vol6-no1-2.pdf`.

Uncomment the `pdf:` line in the issue's frontmatter once the file is in place.
The download button on the issue page, and the "read the complete article in the
print edition" links on metadata-only records, appear automatically when it is
set, and stay hidden when it is not — so the archive never shows a dead link.
